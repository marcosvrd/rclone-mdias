Política de Privacidade

Este aplicativo OAuth é usado somente pelo proprietário para que a ferramenta rclone, instalada no computador dele, acesse o Google Drive da própria conta.

  • Quais dados são acessados: apenas os arquivos e pastas do Google Drive da conta que autorizar o acesso, para copiá-los entre esse Drive e o computador do próprio usuário.
  • Onde ficam: os arquivos são transferidos diretamente entre o Google Drive e o computador do usuário. Nenhum dado passa por servidores de terceiros nem é armazenado pelo desenvolvedor.
  • Compartilhamento: nenhum dado é coletado, vendido, compartilhado ou usado para publicidade.
  • Uso dos dados do Google: o uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
  • Revogar o acesso: a qualquer momento, em myaccount.google.com/permissions.
